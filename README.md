

# EXP 5: COMPARATIVE ANALYSIS OF DIFFERENT TYPES OF PROMPTING PATTERNS AND EXPLAIN WITH VARIOUS TEST SCENARIOS

## Aim

To test and compare how different prompt patterns respond to naïve prompts (broad or unstructured) versus basic prompts (clearer and refined prompts) across multiple scenarios. The experiment analyzes the quality, accuracy, and depth of the generated responses.

# Introduction

Prompt engineering plays an important role in improving the performance of AI systems like OpenAI ChatGPT.
A prompt is an instruction given to an AI model to generate a response. The clarity and structure of prompts directly affect the output quality.

This experiment compares:

Naïve Prompt – Short, unclear, or broad instructions.
Basic Prompt – Clear, structured, and detailed instructions with context.

The objective is to determine whether refined prompts improve the quality, accuracy, and depth of AI-generated responses.

AI Tool Used
ChatGPT by OpenAI
Definition of Prompt Types
1. Naïve Prompt

A simple or vague prompt with minimal instructions.

Example:

“Write a story.”

Characteristics:
Less context
Broad instructions
Minimal details
May produce generic outputs
2. Basic (Refined) Prompt

A clear and structured prompt that gives detailed instructions and context.

Example:

“Write a 200-word science fiction story about a robot helping humans during a flood. Include emotions and a positive ending.”

Characteristics:
Clear objective
Specific instructions
Better context
More focused outputs
Test Scenarios

The following scenarios were selected:

Creative Story Generation
Factual Question Answering

Educational Explanation

Findings
ChatGPT consistently performs better with basic refined prompts.
Clear instructions improve response quality and accuracy.
Detailed prompts help the AI understand the expected output.
Naïve prompts may work for simple tasks but often generate generic responses.
Refined prompts are especially useful for:
Technical explanations
Educational content
Professional writing
Detailed recommendations

## Conclusion

This experiment demonstrates that prompt clarity significantly affects the performance of ChatGPT.
Basic refined prompts produce responses that are:

More accurate
More detailed
Better organized
More useful for users

While naïve prompts can still generate acceptable responses for simple tasks, refined prompts consistently provide higher-quality outputs across multiple scenarios.
